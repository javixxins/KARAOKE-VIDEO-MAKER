3. Revisa y corrige la letra

La letra se detectó automáticamente con sus tiempos. Escucha el audio mientras corriges el texto o los tiempos (en segundos).

Si lo marcas, la previsualización y el vídeo final se generan sin letra — puedes seguir adelante sin detectar ni escribir nada.

Este vídeo se exportará sin letra/subtítulos. Desmarca la casilla de arriba si cambias de opinión.

Línea de tiempo — arrastra las palabras para ajustarlas

Haz clic en una palabra para seleccionarla (Shift/Ctrl+clic para varias) y arrastra para moverla; arrastra varias seleccionadas desde el banco de palabras para colocarlas todas de golpe. Arrastra el borde izquierdo o derecho de una palabra para alargarla o acortarla. Clic derecho sobre una palabra la copia; clic izquierdo en la línea de tiempo la pega ahí (Esc cancela la copia). Mantén pulsada la barra espaciadora y arrastra con el botón derecho para desplazar la vista, y usa la rueda del ratón para acercar/alejar el zoom. Los cambios se guardan solos.
